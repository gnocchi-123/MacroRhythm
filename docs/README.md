# 문서 안내

문서의 기준은 이번 R0 사용자 요구사항, 첨부 원본 개발계획서와 실제 확인한 Git 커밋입니다.
`확정`은 사용자 요구, `확인`은 저장소/실행 증거, `제안`은 채택 전 기술 설계를 뜻합니다.

1. [개발계획 v0.1](development_plan_v0.1.md): 첨부 원문 기반 요구사항·원래 단계 정의·진행 상태.
2. [MacroLens 연동](macrolens_integration.md): 확인한 출력과 제안 계약, 누락·호환·비교 정책.
3. [개발·운영 구조](architecture_operations.md): 정적 사이트, 접근 제어, 일정, 알림, 예산.
4. [R0 검증](r0_validation.md): 실제 수행 범위, 미실행 항목, 후속 결정.
5. [교환 JSON Schema](contracts/macrolens-run-0.1.0.schema.json): Draft 2020-12, 계약 `0.1.0` 제안.
6. [합성 예제 설명](contracts/README.md): 완료·보류·가상 모델 예제의 출처와 검증 한계.

다음 문서들은 미래 기능의 설계이며 R0에서 기능이 동작한다는 뜻이 아닙니다.
원문은 최초 로컬·원격 main에 없었으나 사용자의 첨부로 확보해 대조를 완료했습니다.
[R0 계획 검토](r0_plan_review.md)에 이전 임시 단계표의 수정 사항과 원문별 반영 위치를 기록했습니다.
R0~R5가 v1이며 섹터 점수는 제외합니다. R6는 M4 검증 이후 별도 승인하는 선택 확장입니다.
